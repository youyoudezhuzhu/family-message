# 视觉规范（设计令牌）

> 网页端、Windows Agent、以及未来的 Android 端**共用同一套令牌**。
> 改颜色只改这里的值，三端同步。
>
> 现状对照：网页端在 `web/static/style.css` 的 `:root`；Windows 端在
> `pc-agent/FamilyAgent/PopupWindow.xaml` 的 `Window.Resources`。

---

## 1. 调色板

| 令牌 | 深色（默认） | 浅色（仅网页） | 用途 |
|---|---|---|---|
| `bg` | `#12151C` | `#F3F5F9` | 页面底色、输入框底 |
| `panel` | `#1A1F2B` | `#FFFFFF` | 卡片、面板、下拉浮层 |
| `line` | `#2A3243` | `#E0E5EE` | 分隔线、边框 |
| `fg` | `#E8EDF7` | `#1A2130` | 主文字 |
| `dim` | `#93A0B8` | `#69748A` | 次要文字、说明 |
| `accent` | `#5AC8FA` | `#0A84D8` | 主色：网页发来的消息、主按钮、选中态 |
| `ok` | `#5DDBA0` | `#149E63` | 在线、成功 |
| `warn` | `#F5C451` | `#B7791F` | 设备回复、警告 |
| `bad` | `#F2705E` | `#C0392B` | 离线、失败、危险 |

**语义约定（重要，三端一致）**：

- `accent` 青 = **网页端发来的**（「家里发来的」）
- `warn` 金 = **本机/设备回复的**（「我说的」）
- `ok` 绿 = 在线；`bad` 红 = 离线

> 这条不只是配色偏好 —— 对话区、弹幕流、消息卡片、网页记录**全都用同一套语义色**，
> 用户在任何一端都不用重新学。

### 补充色（深色专用）

| 用途 | 值 |
|---|---|
| 弹窗背景渐变（外 → 内） | `#12151C` → `#182133` |
| 下拉项高亮 | `#2A3B52` |
| 下拉项选中 | `#24405C` |
| 新消息徽标底 | `#1D3550` |

## 2. 圆角

| 元素 | 半径 |
|---|---|
| 卡片 / 面板 / 弹窗 | 14–16 |
| 输入框 / 按钮 / 下拉框 | 9–10 |
| 消息气泡 | 12–14 |
| 徽标 / 小标签 | 5–9 |

---

## 3. 间距

基准 4 的倍数。常用：`8`（紧邻元素）、`12`、`14`、`18`、`24`、`32`（分区）。

---

## 4. 字号

| 场景 | 网页 | Windows | Android 建议 |
|---|---|---|---|
| 页面标题 | 18 | 24 | 20sp |
| 卡片标题 | 15 | 15 | 15sp |
| 正文 | 15–16 | 16 | 15sp |
| 消息气泡正文 | 15 | 20–28（随层级） | 16sp |
| 说明文字 | 12 | 13 | 12sp |
| 时间戳 | 11–12 | 15 | 11sp |

字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", Roboto, sans-serif`
Android 用系统默认（`sans-serif`），不要自己塞字体文件。

## 5. 组件规范

### 消息气泡

```
┌──────────────────────┐
│ [头像]  昵称 · 时间   │   ← 头部小字，按来源着色
│ ┌──────────────────┐ │
│ │ 消息内容          │ │   ← 圆角 12–14，内边距 12×14
│ └──────────────────┘ │
└──────────────────────┘
```

- 网页发来的：**靠左**，头部 `accent` 青
- 本机发的：**靠右**，头部 `warn` 金
- 连续同来源的消息，相邻间距收紧

**层级衰减**（Windows 弹窗对话区用；Android 可选）：

| 距最新 | 字号倍率 | 透明度 |
|---|---|---|
| 0（最新） | 1.00 | 1.00 + 描边高亮 |
| 1 | 0.90 | 0.88 |
| 2 | 0.81 | 0.76 |
| 3+ | 每级 ×0.90，下限 0.55 | 每级 −0.12，下限 0.55 |

### 弹幕式历史流

- 窄条（占宽 27%），**无底色、无边框、无卡片、无滚动条**
- 顶部用透明度蒙版渐隐（线性渐变 0% 透明 → 42% 不透明）
- 每条只有两行小字：`昵称 · 时间` + 内容
- 家里发来的青色，自己回复的金色

### 按钮

| 类型 | 底 | 字 | 用途 |
|---|---|---|---|
| 主按钮 | `accent` | `#06121C` 加粗 | 发送、保存 |
| 次按钮 | `#243044` | `fg` | 取消、返回、删除 |
| 幽灵按钮 | 透明 + `line` 边框 | `dim` | 网页次要操作 |

圆角 9–10，内边距 18×10。悬停：次按钮底变 `#32425C`，幽灵按钮边框变 `accent`。

### 输入框 / 下拉框

- 底 `bg`，边框 `line`，圆角 9–10，内边距 12×9，光标色 `accent`
- 聚焦：边框变 `accent`
- **下拉浮层必须显式指定深色底**（`panel`）和深色文字（`fg`）。
  Windows 默认 WPF 模板在暗色下浮层是**纯白**、白底白字看不清 ——
  必须整个替换 `ControlTemplate`，只设 `Background` 属性是**无效**的。

### 状态点

直径 9–10 圆点。在线 `ok`（可加 25% 透明度外发光），离线 `bad`。

## 6. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 新消息入场 | 340–360ms | 淡入 + 从下方 40–46px 滑入 + 0.97→1.0 微放大，ease-out |
| 已有卡片层级变化 | 260ms | ease-out |
| 下拉浮层 | 150ms | fade |

**禁止**：闪烁、整窗重建式重绘、同一内容反复弹出。
新消息只能**追加**，不能重排已有内容的位置。

## 7. 移植检查清单（Android）

- [ ] 调色板按 §1 定义到 `colors.xml`，语义色别改名
- [ ] 气泡左右 + 语义色与 Windows 端一致
- [ ] 下拉/弹窗用 `panel` 底 + `fg` 字（深色主题下别用系统默认白底）
- [ ] 状态点用 `ok` / `bad`
- [ ] 字体用系统默认，不打包字体文件
- [ ] 新消息入场动画时长与桌面端接近（体感一致）
- [ ] 昵称存本地（`SharedPreferences`），不请求服务端
